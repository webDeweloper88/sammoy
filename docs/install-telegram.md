# Необязательный Telegram при установке

Мастер /install: проверка → активация → кошелёк и роли → Telegram → запуск.

На шаге Telegram доступны «Подключить сейчас» и «Настроить позже в Owner». При пропуске мастер продолжает запуск без бота. При подключении используются существующие защищённые commissioning API: ввод токена BotFather, проверка, привязка владельца по QR/Start и автоматическое обнаружение постов. Пока показан QR, статус привязки обновляется каждые 5 секунд. Токен после успешного сохранения очищается, при уходе со страницы не сохраняется в браузере.

Настройка разрешена только на главном посте; на остальных отображается его номер. Завершение установки не требует Telegram. После завершения управления через commissioning API нет: изменения доступны в Owner → Telegram. Установленные посты не переводились обратно в режим установки ради теста.

Проверка: браузерный тест install.mjs проходит пропуск Telegram и подключение токена/QR с подменой API, возврат по шагам, существующие сетевые настройки, блокировку установки при балансе и завершение по подтверждению. Реальный бот этим тестом не подключался, реальные сообщения не отправлялись.
