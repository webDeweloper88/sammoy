# Отзыв доступа поста

21.11.2026: клиентский протокол 2 для LabrixPay. Серверная спецификация и тестовые сценарии: репозиторий labrixpay, `docs/POST_LIFECYCLE.ru.md`.

При серверном `revocation_pending` runtime запрещает новые клиентские пополнения и карты, сохраняет текущие деньги и позволяет закончить оплаченный сеанс. Служебные карты Owner остаются доступны. Физические деньги во время отзыва попадают в отдельный восстановимый остаток; они не теряются и не смешиваются с оплачиваемым сеансом.

Подтверждение отзыва отправляется только при нулевом остатке, отсутствии сеанса/VIP/перевода/удержанных денег и подтверждённом выключении выходов. Подтверждение содержит точную ревизию команды. До подтверждения в UI сервера показано ожидание.

Онлайн-разрешение действует не более 24 часов; ошибка сети не продлевает его. Старый онлайн-кэш без явного срока ограничен последним успешным получением +24 часа. Явный `offline_cash_only` сохраняет прежнее поведение автономной лицензии. Новый сервер опрашивается раз в 60 секунд, при ожидании отзыва — раз в 5 секунд. Существующее запланированное время первого запроса после обновления может быть позже; при приёмке выполняется ручная синхронизация.

Проверки:
- `tests/test_license_lifecycle.py`: сохранение денег и текущего режима, расход оплаченного dry-fog сеанса до нуля, условия OFF/подтверждения, срок онлайн-кэша.
- `tests/integration/test_cash_ingest_postgres.py`: в одноразовой БД удержание наличных при отзыве без повторного зачисления.
- Регрессия runtime wash/dry_fog/offline и служебных карт.
- Production-сборка Vue.

На CL3566 обязательно сохранять файлы Compose исходного аппаратного профиля (`docker-compose.yml` + `docker-compose.cl3566.yml` для мойки): в профиле есть монтирование `/etc/labrix` для идентичности eMMC и настройки внутренней сети. Базовый Compose без профиля не является эквивалентной заменой.

Платы обновляются без перезагрузки ОС и только в свободном состоянии. На VPS реальные слоты Test_fargona 1–3 не отзывались и не архивировались; у поста 3 сохраняются две платёжные записи. Radxa пока находится в установке и будет проверена как новая плата при явной замене контроллера поста 2.
