# Golden V4 — Cubie A7A, 23.10.2026

Обновляет только проверенную, не запускавшуюся WORK-копию Golden V3 в WSL.
Отдельный результат: G:\001_sammoy\LABRIX-CUBIE-A7A-GOLDEN-V4-20261023.img.
Исходный 64GB backup, экспорт V3, карты и работающие посты не изменяются.
Приложения точно совпадают с подписанным и проверенным на far_2 выпуском
2026.10.23.2. Номер Golden V4 — номер шаблона ОС, а не новый OTA-выпуск.

## Новое

- Изолированный процесс чтения GPIO, IO_BILL_LEVEL_PROCESS=1,
  IO_BILL_SAMPLER_NICE=-10 и SYS_NICE. Для нового потока установлены min pulse
  и min gap 25 мс, max pulse 1000, stuck 5000, startup 500, rate limit 0.
  Поток GPIO создаётся отдельно на каждой новой плате с нулевым счётчиком;
  повторная подготовка никогда не обнуляет поступившие импульсы.
- Отклонение NFC ISO-DEP/неполных метаданных до денежных операций, сообщение
  клиенту. Это дополнительная защита, не универсальный детектор любого телефона.
- Root-служба подписанных обновлений, таймер очистки и Owner-интерфейс.
  В IMG только публичный ключ. Локальный agent.token создаётся на новой плате.
  Подписанный baseline проверяется по вшитому ключу и загруженным config digest;
  installed.json получает версию 2026.10.23.2.
- Зависимости проверки подписи Debian 11 ARM64 устанавливаются из проверенных
  локальных .deb без интернета при первой загрузке. Службы поста и обновлений
  зависят от успешного завершения этого шага. Закрытый ключ выпусков отсутствует.
- Переносимые config digest в манифесте offline Docker. Все пять образов
  сохраняются только для linux/arm64. Загрузка поддерживает classic и
  containerd image store, не привязана к исходному OCI index ID.

Сохранены DHCP, HDMI-1/right, аппаратная проверка до завершения установки,
уникальные Linux/БД/инфраструктурные идентификаторы, owner/admin с первым
паролем labrix и обязательной сменой. Данные, лицензии, Click, Telegram,
роли и адреса старой мойки не переносятся.

Baseline внутри ранее записанного golden image аутентифицируется на дату его
подписанного выпуска: истечение срока каталожной публикации не мешает
установить хранившуюся карту без интернета. Для скачанных OTA-обновлений
действует обычная проверка срока годности, подписи и возраста версии.

## Сборка на Windows

Нужен полный подготовленный пакет LABRIX-Update-Image-V4, включая проверенное
приложение, пять образов, публичные ключи и zerofree-amd64. Одних исходников
скриптов недостаточно. Распаковать в G:\001_sammoy и запустить
10-UPDATE-IMAGE-V4.cmd. Проверяются hash исходного WORK, происхождение V3,
чистое незапущенное состояние, разделы, свободное место Windows/WSL. V4 не
перезаписывает старые экспорты. При ошибке не повторять автоматически:
сначала проверить состояние; .partial не является готовым образом.

Физическая запись новой карты через balenaEtcher выполняется только после
IMAGE READY TO FLASH. Первая загрузка экспортированного V4 на Cubie A7A и
аппаратная приёмка остаются обязательными — тесты сборщика их не заменяют.
