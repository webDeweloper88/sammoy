# Вызов оператора и контакты LABRIX

## Настройки

Owner → «Экран мойки»: включение вызова оператора, телефон оператора и Telegram chat ID. Пустой chat ID означает привязанного Telegram-владельца; для группы бот должен быть её участником. Telegram-бот должен быть настроен и включён. Настройки оператора задаются отдельно на каждом посту; по умолчанию вызов выключен.

Admin → «Подключение»: телефоны производителя и HTTPS-ссылки на Telegram, Instagram и YouTube. Эти настройки также локальные. Значения по умолчанию:

- Маркетинг: +998 91 111 69 29.
- Программист: +998 91 667 62 28.
- Оборудование и электрика: +998 94 584 13 01.
- Социальные аккаунты: labrixwash.

Footer показывает номер поста, включённую кнопку вызова, телефон оператора, производителя и социальные ссылки. Окно контактов производителя содержит три телефона и три QR-кода. Телефоны отображаются без запуска системного приложения звонков.

## Доставка

Клиент создаёт UUID запроса, сервер определяет мойку и номер поста. В общей мойке запрос направляется по подписанному внутреннему протоколу на главный пост. Сетевая отправка не удерживает блокировку финансовых операций. Второй пост не отправляет Telegram самостоятельно.

Очередь `operator-calls.sqlite3` хранится в каталоге данных telegram-reports. Повторный UUID не создаёт новое сообщение; ограничение — один вызов с поста за 120 секунд. Ожидающий вызов истекает через 5 минут. При отсутствии соединения допускается повтор; при неоднозначном результате отправки повтор автоматически не выполняется. «Отправлено» показывается только после подтверждения Telegram. Это подтверждение доставки сообщения, а не принятия вызова человеком.

Очередь не реплицируется вместе с кошельком. При потере главного поста доставка его очереди не гарантируется; клиенту остаётся телефон оператора. Неотправленные вызовы на выключенном сервисе не отправляются до его включения; устаревшие затем истекают. Очистка записей старше 31 дня выполняется при поступлении нового вызова. Копия на той же microSD не защищает от отказа носителя.

Публичная конфигурация не содержит chat ID или токен бота. Уведомления не содержат UID карт или балансов. Режим предпросмотра не отправляет запросы вызова.

## VIP и язык

При VIP-сеансе наличные и новый QR-платёж недоступны в интерфейсе с явным объяснением необходимости завершить VIP. Ранее созданный QR продолжает отслеживаться. Это ограничение UI не является подтверждением аппаратной блокировки купюроприёмника.

Узбекские подсказки используют «pistolet tepkisi».
