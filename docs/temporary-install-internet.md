# Временный интернет при установке

На шагах «Активация», «Telegram» и «Запуск» доступен блок подключения к точке доступа телефона. Ethernet и его статический адрес сохраняются: кошелёк и локальные посты продолжают использовать роутер мойки.

1. Включить точку доступа телефона (при необходимости 2,4 ГГц).
2. Нажать «Подключить Wi-Fi телефона», найти сеть или ввести SSID и пароль.
3. Подключиться и подтвердить в течение 90 секунд. Без подтверждения NetworkManager восстанавливает прежнее подключение Wi-Fi.
4. Проверить доступность сервера активации, активировать пост и при желании настроить Telegram.
5. При завершении установки по умолчанию выбрано отключение временного Wi-Fi через 30 секунд. Пароль и профиль не сохраняются на диск. Если отключение отложено, подключение удаляется через 2 часа; после перезагрузки оно не восстанавливается.

Временная сеть использует меньшую метрику маршрута и приоритет DNS. Совпадение подсетей телефона и Ethernet блокирует подтверждение и вызывает откат; нужно изменить сеть телефона либо использовать активацию через подписанный файл. На каждом посту подключение выполняется отдельно. При отключении восстанавливается прежний Wi-Fi, если он был; сохранённые профили не удаляются. Admin может отключить временное подключение в настройках сети после установки.

Корневая служба хранит только идентификаторы, SSID и сроки в `/run/sammoy2-admin/temporary-wifi.json`, без пароля. NetworkManager получает профиль с `persist=memory` и `autoconnect=false`. Таймер очистки работает вне backend и переживает перезапуск сетевого агента. Общий каталог сокетов обязательно имеет `RuntimeDirectoryPreserve=yes` в обеих службах обслуживания.

Проверено автоматически: память вместо постоянного профиля, отсутствие GetSecrets/Update2 при подтверждении, приоритет маршрутов/DNS, откат пересекающихся подсетей, удаление временного профиля и восстановление прежнего Wi-Fi, задержка очистки, запрет изменения после установки, свободный пост, браузерный сценарий SSID/пароль/подтверждение/завершение. Реальное подключение телефона и работа при отсутствии Ethernet WAN требуют аппаратной проверки.
