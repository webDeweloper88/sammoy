# Приёмка до golden image и до работы с клиентами

Образ для разработки/стенда и промышленный выпуск — разные контрольные точки.
Не выдавать непройденные аппаратные проверки за успешные программные тесты.

| Проверка | Подтверждено | Осталось |
|---|---|---|
| Click | Тесты начисления, бонуса, повторов/поздних уведомлений | Реальная оплата, callback, отмена, повтор, восстановление при потере сети, отчёт |
| Два дизайна UI | Компоненты и browser tests | Обе темы light/dark на панели 1080×1920: контраст с 2–4 м, все режимы, air/vacuum, free/paid pause, оплата, клавиатура, ошибки, авто-время |
| Реле | 8 выходов без нагрузки, one-hot/readback | Замеры полного отклика IN3 и смены режимов, обе паузы, bypass, нулевой баланс; реальные нагрузки отдельно |
| NV9 | Реальные 10000 + 1000 бонус, durable journal | Номиналы, повтор, питание/помехи, аппаратный inhibit, восстановление |
| NFC/VIP | PN532 online и чтение UID/удержание | Полный money/bonus cycle обычной карты; VIP day limit/visit; смена поста без обновления паузы |
| Две Radxa | Вторая доступна 10.10.10.7, подготовлена ОС | Общая активация, wallet/VIP replication, ручной failover, fencing, возврат узла, сверка денег |
| Backup | Отдельное восстановление PostgreSQL и локальный timer | Носитель вне microSD, восстановление всего узла и возврат в пару |
| Golden | Экспорт без live data, отдельные секреты, first-boot scripts | Автозапуск, ОС/SSH identity, отсутствие секретов сборщика, отключение при съёме, повторная запись/загрузка; физическая карта 32 GB |
| Выпуск | Локальные Docker images | Версионированный manifest, фиксированные image digests, update/rollback без отката финансов, ограниченный пилот |

Перед фиксацией первого golden-кандидата: обе темы визуально принять, проверить
startup /launch → /install, уникальную идентичность копии, пустые деньги/карты,
перезапуск браузера и служб, отсутствие скопированных паролей/активации/токенов.
Непроверенные платежи/оборудование отмечать в манифесте кандидата; такой кандидат
не является допуском к обслуживанию клиентов.

Вторую плату готовим без simulation и без io-helper, пока нет serial/I2C7.
UI сообщает о неготовности оборудования, установка не может быть завершена.
Проверенные X11/ILITEK и GPIO назначения не менять в рамках развёртывания.
