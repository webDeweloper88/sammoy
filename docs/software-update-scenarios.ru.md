# Проверка сценариев обновления — 23.10.2026

На объекте far_2 Owner выполнил две последовательные установки:
2026.10.23.1 и 2026.10.23.2. У обоих постов квитанции completed,
очереди завершены без ошибок. Сначала обновлялся резервный пост 2,
затем главный 1. После версии 2 владелец проверил купюры и режимы обоих
постов. Это фактические проверки оборудования, а не имитация.

Дополнительно в изолированных автоматических тестах проверены сценарии:

| Условие | Ожидаемое поведение |
| --- | --- |
| Открыт сеанс, есть баланс, активна услуга или перевод | Пост не останавливается для установки |
| Пост занят после начала загрузки | Повторная проверка останавливает установку до остановки сервисов |
| Обычный пост недоступен | Другие готовые посты могут обновиться, главный ждёт остальные |
| Сеанс закончился | Очередь продолжает прежнюю операцию с тем же UUID |
| Пропал ответ на установку | Проверяется прежняя квитанция, вторая установка не создаётся |
| Недоступен пост с установкой в работе | Остальные установки не запускаются параллельно |
| Повтор того же запроса | Возвращается прежняя операция |
| Другой запрос во время установки | Отклоняется |
| Изменены роли кошелька | Очередь останавливается для проверки |
| Ошибка новой версии при проверке здоровья | Возвращаются прежние Docker-образы; старая БД не восстанавливается |
| Во время установки появился новый клиентский сеанс | Автооткат не прерывает его; needs_review |
| Не запустилась и прежняя версия | needs_review; успех не показывается |
| Импульс пришёл перед переключением | Новая версия не активируется, возвращаются сервисы |
| Не создалась резервная копия | Новые образы не активируются |
| Нет места, подпись неверна или архив опасен | Установка отклоняется до остановки поста |
| Истекли 48 часов | Удаляются управляемые копии успешных/откаченных операций; needs_review сохраняется |
| Попытка установить старый номер выпуска | Отклоняется |

Результаты: 329 тестов backend (из них 16 сценариев очереди/блокировок),
17 тестов root-установщика. Проверки неисправностей используют временные
каталоги и подмену границ Docker/сети. Они проверяют алгоритм, но не заменяют
аппаратное испытание отключения питания, отказа накопителя или реального
отката Docker на отдельной тестовой плате. На работающих постах такие отказы
не создавались. Изменены только тесты и этот отчёт; новый выпуск приложения
для них не требуется.

В текущем интерфейсе нет кнопки произвольного понижения версии. Автоматический
откат относится к неуспешной установке. Если уже успешно установленный выпуск
потребуется вернуть, нужен отдельно проверенный и подписанный выпуск с новым
номером и совместимыми прежними образами. Откат БД поверх новых денег запрещён.
