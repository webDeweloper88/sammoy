# Бесплатная пауза локальной карты

Локальный режим раньше закрывал денежный сеанс при сохранении остатка на карту и выдавал новый бюджет при возврате. Это поведение не зависело от Cubie/CL3566.

Теперь в существующем rfid_cards.metadata.local_pause_visits сохраняются schema1, оставшиеся секунды (включая дробную часть) и expires_at отдельно для wash/dry_fog. Метаданные записываются под row lock в одной транзакции с денежным/бонусным остатком. Возврат списывает деньги и consume metadata в одной транзакции; восстановленный бюджет сразу записывается в wash_sessions.metadata для power recovery. Денежные таблицы и действующий shared-wallet протокол не меняются.

Визит на карте истекает через30минут после сохранения; это тот же default, что shared-wallet. До истечения повторные переводы сохраняют остаток, в том числе0; при объединении с уже имеющимся балансом выбирается меньший бюджет. Изменение тарифа не увеличивает активный сохранённый бюджет сверх нового лимита. Expiry не списывает деньги и бонусы. Legacy карта без сохранённых данных получает начальный лимит один раз; следующие сохранения уже переносят контекст. Невалидный сохранённый контекст даёт0секунд, не новую бесплатную паузу.

Проверки:8unit/runtime tests,16wash regressions,43wallet/bonus/card guard tests PASS. Отдельный PostgreSQL тест в disposable schema проверяет5циклов save/load с10000+2000bonus, дробным/нулевым бюджетом, сохранением sessionmetadata и expiry; PASS. Боевые карты в тестах не изменяются.

Развёртывание на CL10.10.10.26: перед заменой engine проверены нулевой баланс/отсутствие сеанса, сделан pg_dump в root-only /var/backups/labrix/local-card-pause/verified-before-*.sql.gz с проверкой gzip/header. Старый image tag before-local-card-pause сохранён. Обновляется только engine, без helper recreation и сброса журналов/балансов. Radxa требует отдельного выпуска/развёртывания; изменение исходников само не обновляет установленные посты.
