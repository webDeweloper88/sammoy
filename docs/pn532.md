# PN532 on Radxa Cubie A7A

Wiring (physical header pin numbers): VCC=1 (3.3 V), GND=6,
SDA=3 (PJ23), SCL=5 (PJ22). Set the PN532 module to I2C mode.
The enabled `sun60iw2p1-twi7` overlay exposes `/dev/i2c-7`.
The reader uses address `0x24`.

On this host, Sunxi TWI `drv` mode returned `EINVAL` when sending PN532
commands. Switching TWI7 to `engine` mode returned firmware `(50, 1, 6, 7)`
and successfully completed SAM configuration. The systemd unit in `deploy/`
reapplies engine mode before Docker starts after a reboot.

Deploy when the wash is idle: the script restarts io-helper and wash-engine,
whose startup/shutdown code switches outputs off.

```sh
sudo sh /opt/sammoy/sammoy2/deploy/enable-pn532.sh
curl http://127.0.0.1:8080/rfid/latest
curl 'http://127.0.0.1:8080/rfid/events?since=0'
```

The script builds both service images, enables the boot-time I2C setup,
recreates the two containers and checks that the actual reader is online.
`/rfid/latest` reports firmware, errors, card presence and the latest UID.
`/rfid/events` emits one event per presentation; holding a card does not
continuously create events. Removing it for 0.75 seconds permits another
event. The wash-engine consumes these events using its existing RFID logic.

For a standalone reader test, stop io-helper first to avoid two processes
using the reader simultaneously, then run `services/io-helper/test_pn532.py`
in an environment with the io-helper Python dependencies installed.
