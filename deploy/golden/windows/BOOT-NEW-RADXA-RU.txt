LABRIX — загрузочная microSD для новой Radxa Cubie A7A

1. Распакуйте ВЕСЬ архив в G:\001_sammoy.
2. Запустите 06-BUILD-IMAGE.cmd. Это автоматически очистит рабочую копию,
   уменьшит ext4/GPT, затрёт освобождённые блоки и сохранит готовый файл:
   G:\001_sammoy\LABRIX-CUBIE-A7A-GOLDEN-20261021.img
   Итоговый размер около 16,33 GiB. Оригинал поста 2 не изменяется.
   Этап может занять несколько минут. Не закрывайте окно до IMAGE READY TO FLASH.
3. Вставьте НОВУЮ 64-GB microSD третьего поста. Запустите 07-WRITE-NEW-CARD.cmd.
   Подтвердите запрос Windows на запуск от администратора, выберите физический
   номер новой карты и введите WRITE NEW N (N — показанный номер).
   ВНИМАНИЕ: выбранная НОВАЯ карта будет полностью перезаписана.
4. Дождитесь CARD VERIFIED, безопасно извлеките карту и вставьте её в
   ВЫКЛЮЧЕННУЮ новую Radxa. Подключите экран/Ethernet и включите питание.
5. Первый запуск дольше обычного: загружаются локальные Docker-образы.
   Появятся заставка LABRIX и мастер /install. Пост ещё не активирован.
   Для существующей мойки используйте отдельный код активации ПОСТА 3.
   Мойка/сухой туман выбирается при установке. Главный 1 и резервный 2 сохраняются.

Новая плата сначала получает Ethernet-адрес по DHCP; старые IP 10.10.10.7/8
не переносятся. Поворот экрана сохраняется. Файловая система расширяется на карту.
Старые базы, лицензия, Telegram, пароли и ключи в образ не входят.
На действующих постах ничего не перезапускается и данные не удаляются.

При ошибке пришлите её текст. Не записывайте файл .partial.
Если Windows предлагает форматировать Linux-раздел после записи — ОТМЕНА.
Исходный .img на G: и родную карту поста 2 сохраните отдельно.

Закрытый ключ установщика остаётся в C:\Users\admin\.ssh\labrix_installer_ed25519.
Для будущего обслуживания новой платы используйте этот ключ; начальные
пароли Owner/Admin и sudo доступны по SSH в ~/labrix-first-login.txt.
Для загрузки с microSD вводить этот ключ не требуется.

Образ предназначен для той же Cubie A7A с тем же экраном. Это не образ CL3566-A.
Первая загрузка новой физической платы ещё требует проверки.
