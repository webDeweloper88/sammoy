LABRIX — доступ установщика к новым платам

Зачем: образ не должен переносить старый системный пароль поста 2.
Публичный SSH-ключ позволит установщику войти на новую плату после первого
запуска. Закрытый ключ остаётся только на вашем Windows-компьютере.
Это ключ доступа установщика, а не код лицензии и не ключ общего кошелька.

1. Распакуйте пакет в G:\001_sammoy.
2. Запустите 04-INSTALLER-KEY.cmd обычным двойным щелчком.
3. При первом запуске придумайте пароль ключа и повторите его.
   При вводе символы не показываются. Пароль сохраните у себя.
4. Пришлите только строку, начинающуюся с ssh-ed25519.
   Файл без расширения .pub и пароль никому не отправляйте.

Ключ: %USERPROFILE%\.ssh\labrix_installer_ed25519
Повторный запуск показывает существующий публичный ключ, не заменяя его.
При неполной паре файлов скрипт остановится, ничего не перезаписывая.
Образ, рабочая копия, SD-карты и действующие посты не изменяются.
