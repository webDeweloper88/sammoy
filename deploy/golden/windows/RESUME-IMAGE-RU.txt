LABRIX — завершить создание IMG после ошибки No space left on device

1. Распакуйте этот небольшой архив в G:\001_sammoy.
   Старую папку LABRIX-New-Radxa оставьте на месте, не заменяйте её.
2. Запустите 06-RESUME-IMAGE.cmd.
3. Дождитесь IMAGE READY TO FLASH. Готовый файл:
   G:\001_sammoy\LABRIX-CUBIE-A7A-GOLDEN-20261021.img
4. Запишите этот файл на НОВУЮ microSD через balenaEtcher.
   Скрипт 07-WRITE-NEW-CARD.cmd использовать не нужно.

Продолжение проверяет уменьшенный GPT, UUID и загрузочные области по оригиналу,
удаляет только оставшийся временный .labrix-zero-free, проверяет ext4,
обнуляет свободные блоки отключённой файловой системы и проверяет их повторно.
Затем сохраняет IMG на G: и сверяет полный SHA-256 сохранённого файла.
Две проверки свободных блоков и проверка IMG могут занять несколько минут.

Очистка приложения и уменьшение разделов не повторяются. Новый исходный образ
копировать не нужно. Действующие посты не меняются. SD-карты не открываются.
Оригинальный LABRIX-SOURCE-POST2-20261021-121320.img читается только для проверки.
Если проверка останавливается, пришлите полный текст ошибки.

Архив включает маленькую утилиту zerofree для Ubuntu/WSL x86_64.
Она не устанавливается в образ Radxa. Интернет для её загрузки не нужен.
Исходники/лицензия и происхождение утилиты находятся в third-party.
